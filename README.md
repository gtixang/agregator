# Agregator

Agregator — веб-приложение для поиска и выбора онлайн-курсов и образовательных школ. Пользователь может просматривать каталог, выбирать тематические направления, применять фильтры и изучать подробную информацию о курсах, школах и отзывах.

Проект находится в активной разработке.

Демо: [agregator-nu.vercel.app](https://agregator-nu.vercel.app/)

## Реализовано

- каталог онлайн-курсов с данными из Supabase;
- фильтрация курсов по цене, длительности, уровню, школе, наличию стажировки и сертификата;
- выбор тематического направления курса;
- страницы курсов, школ и отзывов;
- просмотр отзывов о школе;
- просмотр курсов конкретной школы;
- форма создания отзыва с обязательными полями имени, заголовка, текста и оценки;
- обработка состояний загрузки, пустого результата и ошибки;


## В планах

- подключение полноценного поиска по курсам из поля в шапке;
- поиск с автодополнением;
- полноценная страница с подробной информацией о курсе;
- страница 'О преподавателе'
- пагинация каталога;

## Технологический стек

- Angular 20;
- TypeScript;
- RxJS;
- Supabase и Supabase PostgREST;
- SCSS;
- ESLint;
- Prettier;

## Архитектура

Проект разработан с использованием архитектуры FSD (Feature-Sliced Design). Код приложения разделён на страницы, виджеты, функциональные модули, бизнес-сущности и общие компоненты и сервисы.

## Структура проекта

```text
src/
└── app/
    ├── pages/       страницы приложения
    ├── widgets/     составные блоки интерфейса
    ├── features/    пользовательские функции
    ├── entities/    курсы, школы, категории и отзывы
    └── shared/      общие UI-компоненты, модели и API
```

Маршруты приложения:

- `/` — главная страница;
- `/courses` — каталог курсов;
- `/schools` — каталог школ;
- `/course/:id` — страница курса;
- `/school/:id` — курсы школы;
- `/school/:id/reviews` — отзывы о школе.

## Работа с данными

Для доступа к данным используется Supabase. Сервисы сущностей выполняют запросы к API, преобразуют полученные DTO в модели приложения и возвращают асинхронные состояния через RxJS.

Конфигурация Supabase находится в файлах окружения:

```text
src/environments/environment.ts
src/environments/environment.prod.ts
```

Используемые параметры:

- `supabaseUrl`;
- `supabaseKey`.

## Запуск проекта

Установите зависимости:

```bash
npm install
```

Запустите сервер разработки:

```bash
npm start
```

Приложение будет доступно по адресу `http://localhost:4200/`.

## Проверка кода

```bash
npm run build

npm run lint
```

Для форматирования файлов:

```bash
npm run prettier
```
