# 📚 Курсовой Агрегатор (Course & School Aggregator)

Современное веб-приложение для поиска, сравнения и выбора образовательных курсов и онлайн-школ. Проект собирает актуальную информацию об обучающих программах, предоставляет честные отзывы пользователей и детальные карточки учебных заведений.

🔗 **Живое демо проекта:** [agregator-nu.vercel.app](https://vercel.app)

---

## ✨ Ключевые функции (Features)

* **Умный поиск и каталогизация:** Удобные списки онлайн-курсов и школ с динамической фильтрацией и сортировкой по различным критериям.
* **Детальные карточки:** Информативные страницы курсов и онлайн-школ, содержащие полную программу обучения, цены и условия.
* **Система отзывов:** Интегрированный блок пользовательских рецензий для формирования прозрачного рейтинга учебных заведений.
* **Реактивное управление данными:** Использование возможностей RxJS для плавного, бесшовного обновления интерфейса без лишних перезагрузок страниц.
* **Облачный бэкенд:** Интеграция с платформой Supabase для надежного хранения данных, работы с API и авторизации.

---

## 🏗 Архитектура проекта

Проект спроектирован по методологии **Feature-Driven (Feature-Sliced Design)**, что обеспечивает слабую связанность модулей и высокую масштабируемость кода:

* `entities/` — Бизнес-сущности приложения (курсы, школы, отзывы, категории).
* `features/` — Пользовательский функционал и интерактивные блоки (логика фильтрации, списки элементов).
* `pages/` — Страницы приложения (Главная, Детали курса, Страницы школ, 404).
* `widgets/` — Самостоятельные и переиспользуемые крупные блоки интерфейса (Header, Footer).
* `shared/` — Переиспользуемый код, независимый от бизнес-логики (API-клиенты Supabase, общие UI-компоненты, типы данных).

## 🔧 Технологический стек (Tech Stack)

* **Core & Framework:** Angular (v20+), TypeScript, RxJS
* **UI & Styles:** Angular Material, Angular CDK, Sass (SCSS)
* **Backend & API:** Supabase Client (@supabase/supabase-js)
* **Code Quality:** ESLint, Prettier, Husky, lint-staged
* **Testing:** Jasmine, Karma

## 🚀 Локальный запуск (Getting Started)

1. Клонируйте репозиторий и перейдите в папку проекта.
2. Установите необходимые зависимости:
   ```bash
   npm install
   ```
3. Запустите локальный сервер разработки:
   ```bash
   npm start
   ```
   Приложение будет доступно по адресу `http://localhost:4200/`.

4. Другие доступные команды:
   * `npm run build` — Сборка проекта для продакшена.
   * `npm test` — Запуск модульных тестов.
   * `npm run lint` — Проверка качества кода и форматирования.
